# Microsoft Store リスト - 日本語 (Japan)

## 製品名
Tapster

## 簡単な説明
キー長押し、自動クリック、高精度マクロ記録・再生に対応した、Windows 11 Fluent デザイン採用の高速キーボード＆マウス自動化アシスタント。

## 詳細説明
Tapster は、反復的なキーボード入力やマウス操作を効率化するために設計された、最新の Windows 向けネイティブ自動化ツールです。軽量かつ高速な Win32 アンマネージドコアを採用し、Windows 11 の洗練された Fluent デザイン（Mica 素材）とシームレスに調和します。

ゲーム内でのキーの継続的な長押し、仮想マシンやリモートデスクトップへの定型テキスト自動入力、高頻度のマウスクリック、または操作手順のマクロ記録・再生など、あらゆる自動化を完全オフラインで安全に実行します。

主な機能：
- **キーの継続長押し＆ローテーション**：単一キーまたは修飾キーの組み合わせを自動で押し続けます。複数のキーコンボを指定秒数ごとに順次切り替えるローテーション機能も搭載。
- **高速オートクリッカー**：左・右・中央クリックに対応。ミリ秒単位の間隔調整、指定回数クリック、または無限クリックが可能。
- **高精度マクロレコーダー**：低レベルフックにより、ミリ秒以下の精度でマウスやキー操作の間隔を忠実に記録・再生（0.25倍〜5.0倍速対応）。
- **インタラクティブな仮想キーボード**：押下されているキーやアクティブ状態がリアルタイムで発光表示される視覚的レイアウト。
- **Windows 11 Fluent UI**：ネイティブな Mica 背景、ライト/ダークモード対応、システムトレイ常駐機能。
- **グローバルホットキー呼び出し**：どの画面からでも `Ctrl + Alt + T` を押すだけで瞬時に呼び出し可能。
- **完全ローカル＆プライバシー保護**：ネットワーク通信は一切行わず、常駐サービスによる余分なリソース消費もありません。

## 主な機能
- キーの継続長押しおよび複数キーのシーケンスローテーション
- ミリ秒精度の高速自動マウスクリック（左/右/中央）
- 正確なデスクトップ操作マクロの記録と速度調整再生
- リアルタイムで状態がわかる5列仮想キーボード表示
- システムトレイ最小化とグローバルホットキー (Ctrl+Alt+T) による瞬間起動
- 美しい Windows 11 Fluent デザインとネイティブ Mica 素材
- 100% オフライン・安全なローカル実行
