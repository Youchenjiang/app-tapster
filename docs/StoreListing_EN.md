# Microsoft Store Listing - English (United States)

## Product Name
Tapster

## Short Description
High-performance native keyboard & mouse automation assistant with Fluent UI, auto clicker, continuous key holding, and high-precision macro recording.

## Description
Tapster is a modern, ultra-responsive Windows automation tool designed to eliminate repetitive typing, holding, and clicking tasks. Engineered with a pure Win32 unmanaged core and wrapped in a beautiful Windows 11 Fluent interface (WinUI 3 with Mica material), Tapster provides unmatched precision and zero bloat.

Whether you need to hold down keys during complex gaming maneuvers, automate long text entries in virtual desktop/VNC environments, perform high-frequency mouse clicks, or record and replay precision desktop macros, Tapster does it effortlessly and completely offline.

Key Features:
- **Continuous Key Holding & Rotation**: Hold down single or combination keys continuously, or configure a timed rotation sequence across multiple key combinations.
- **High-Speed Auto Clicker**: Perform unlimited or count-bounded mouse clicks (Left, Right, Middle) with millisecond-accurate interval controls.
- **High-Precision Macro Recorder**: Record full mouse clicks and keystroke sequences with microsecond timing precision, and replay them at adjustable speeds (0.25x - 5.0x).
- **Interactive Virtual Keyboard**: Visual 5-row keyboard matrix providing real-time visual feedback for active and held keys.
- **Modern Windows 11 Fluent UI**: Native Mica backdrop, smooth animations, dark/light theme alignment, and system tray integration.
- **Global Wake Hotkey**: Press `Ctrl + Alt + T` anywhere in Windows to instantly summon Tapster without navigating through windows.
- **100% Privacy & Offline**: Zero network telemetry, zero tracking, and no external background daemon overhead.
