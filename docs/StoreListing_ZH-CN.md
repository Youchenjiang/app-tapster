# Microsoft Store 清单 - 中文 (简体)

## 产品名称
Tapster

## 简短描述
现代化极速原生键鼠自动化助手：支持按键长按、定时轮换、高频连点、微秒级宏录制与 Windows 11 Fluent 现代设计。

## 完整描述
Tapster 是一款专为 Windows 10 与 Windows 11 用户打造的轻量高效键鼠自动化与辅助工具。底层基于纯 Win32 API 驱动，搭配精致的 Windows 11 Fluent 现代设计风格（Mica 材质与圆角效果），提供极致精准的操作体验，无臃肿依赖。

无论您是在游戏中需要持续长按特定键位、在远程桌面/虚拟机环境中自动输入长段文本、需要毫秒级高频鼠标连点，还是希望一键录制并多倍速回放桌面操作，Tapster 都能在 100% 离线环境下顺畅完成。

核心功能：
- **按键持续长按与多段轮换**：支持单键或组合键无限按住，亦可自定义多组按键的定时轮换列表，按顺序自动循环。
- **高频自动连点器**：支持鼠标左键、右键与中键连点，可设定无限次数或指定次数，点击间隔支持精确微调。
- **微秒级宏录制与回放**：采用底层全局钩子精准记录鼠标点击与按键操作间隔，支持 0.25 倍至 5 倍速自由回放。
- **直观虚拟键盘**：内置 5 排标准键盘网格，实时以可视化效果呈现当前处于激活或长按状态的键位。
- **Windows 11 Fluent 界面**：原生 Mica 材质背景、深浅色主题自适应，支持最小化至系统托盘常驻。
- **全局一键唤醒**：在任何窗口下按下全局快捷键 `Ctrl + Alt + T`，即可瞬间呼出主界面。
- **100% 本地隐私与轻量**：无任何网络外连、零数据遥测，无后台额外常驻服务。

## 产品特性
- 支持按键持续长按与多按键轮换序列
- 毫秒级高频鼠标连点（左键/右键/中键）
- 硬件级精准宏录制与多倍速回放
- 内置 5 排交互式虚拟键盘状态面板
- 最小化至系统托盘与全局快捷键唤醒 (Ctrl+Alt+T)
- 现代 Windows 11 Fluent 视觉设计与 Mica 材质
- 100% 本地运行，完全保护个人隐私安全
