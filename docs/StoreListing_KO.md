# Microsoft Store 목록 - 한국어 (Korea)

## 제품 이름
Tapster

## 간단한 설명
키 지속 누르기, 초고속 오토클릭, 정밀 매크로 녹화 및 재생을 지원하는 Windows 11 Fluent 디자인 기반 네이티브 자동화 도구.

## 상세 설명
Tapster는 반복적인 타이핑, 키 누름, 마우스 클릭 작업을 손쉽게 자동화할 수 있도록 설계된 현대적인 Windows 네이티브 도구입니다. 순수 Win32 언매니지드 코어로 구축되어 뛰어난 반응성을 자랑하며, Windows 11 Fluent 디자인(Mica 소재)과 어우러져 세련된 사용 환경을 제공합니다.

게임 플레이 중 특정 키를 계속 누르고 있어야 하거나, 원격 데스크톱/VNC 환경에서 긴 텍스트를 자동으로 입력하거나, 밀리초 단위의 연속 클릭이 필요하거나, 복잡한 마우스/키보드 작업을 녹화하여 원하는 배속으로 재실행해야 할 때 Tapster는 완전히 오프라인에서 안전하게 작업을 수행합니다.

주요 기능:
- **키 지속 누름 및 순차 로테이션**: 단일 키 또는 조합 키를 지속적으로 누르고 있거나, 여러 개의 키 조합을 시간별로 순차 실행하는 로테이션을 지원합니다.
- **초고속 오토클릭커**: 마우스 좌클릭, 우클릭, 휠클릭을 지원하며, 밀리초 단위 간격 조절 및 횟수 지정 또는 무제한 클릭이 가능합니다.
- **고정밀 매크로 녹화 및 재생**: 하위 수준 후킹을 통해 키보드와 마우스 동작 간격을 정밀하게 기록하고 0.25배속부터 5배속까지 자유롭게 재생합니다.
- **직관적인 가상 키보드**: 실시간으로 눌려 있는 키와 활성 상태를 한눈에 파악할 수 있는 5열 가상 키보드 매트릭스를 제공합니다.
- **Windows 11 Fluent UI**: 네이티브 Mica 반투명 효과, 다크/라이트 테마 자동 반영, 시스템 트레이 최소화 대기를 지원합니다.
- **글로벌 단축키 호출**: 어떤 작업 중이든 `Ctrl + Alt + T`를 누르면 화면 전환 없이 즉시 Tapster를 화면에 띄울 수 있습니다.
- **100% 로컬 프라이버시**: 네트워크 통신이 전혀 없으며, 백그라운드 상주 데몬에 의한 불필요한 시스템 자원 낭비가 없습니다.

## 제품 기능 목록
- 키 지속 누르기 및 다중 키 로테이션 시퀀스
- 밀리초 단위 간격의 고주파 마우스 오토클릭
- 정밀한 데스크톱 동작 매크로 녹화 및 가변 배속 재생
- 실시간 상태를 보여주는 5열 가상 키보드 뷰
- 시스템 트레이 최소화 및 글로벌 단축키 (Ctrl+Alt+T) 호출
- 미려한 Windows 11 Fluent 디자인과 Mica 소재
- 100% 오프라인 안전 실행 및 개인정보 보호
