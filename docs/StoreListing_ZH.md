# Microsoft Store 清單 - 中文 (台灣)

## 產品名稱
Tapster

## 簡短描述
現代化極速原生鍵鼠自動化助手：支援持續長按、定時輪替、高頻連點、微秒級巨集錄製與現代 Windows 11 Fluent 設計。

## 完整描述
Tapster 是一款專為 Windows 10 與 Windows 11 使用者打造的極速原生鍵鼠自動化與輔助工具。底層採用純粹的 Win32 API 驅動，搭配優雅精緻的 Windows 11 Fluent Design（Mica 材質與圓角陰影），提供極致精確的操作體驗且絕不浪費系統資源。

不論您是在遊戲中需要持續長按特定按鍵、在遠端桌面/虛擬機環境中自動輸入長段文本、需要毫秒級高頻連點滑鼠，或是希望一鍵錄製並多倍速回放桌面操作，Tapster 都能在 100% 離線環境下完美達成。

核心特色：
- **按鍵持續長按與多段輪替**：支援單鍵或組合鍵無限持續按住，亦可自訂多組按鍵的時間輪替清單，自動依序執行。
- **高頻自動連點器**：支援滑鼠左鍵、右鍵與中鍵連點，可設定無限次數或固定次數，間隔可精確微調至毫秒級。
- **微秒級巨集錄製與回放**：透過全域底層鉤子精確記錄滑鼠點擊與鍵盤操作時間差，支援 0.25 倍至 5 倍速自訂回放。
- **直覺式虛擬鍵盤**：內建 5 排標準鍵盤網格，長按與啟用狀態即時以視覺化發光呈現。
- **Windows 11 Fluent 介面**：原生 Mica 半透明材質、深淺色主題自適應，支援最小化至系統匣常駐。
- **全域一鍵喚醒**：在任何視窗按下全域熱鍵 `Ctrl + Alt + T`，即可瞬間呼叫出主視窗。
- **100% 本地隱私與輕量**：零網路通訊、零追蹤遙測，無後台常駐臃腫服務。

## 產品亮點
- 支援按鍵持續長按與多鍵輪替序列
- 毫秒級高頻滑鼠連點（左鍵/右鍵/中鍵）
- 高精度巨集錄製與多倍速回放
- 內建 5 排互動式虛擬鍵盤狀態檢視
- 最小化至系統匣與全域快捷鍵喚醒 (Ctrl+Alt+T)
- 現代 Windows 11 Fluent Design 與原生 Mica 材質
- 100% 本機執行，絕對保護個人資料隱私
